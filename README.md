## Open-Source & Self-Hosted DMS

- [Docspell](https://docspell.org/) - Docspell is an open-source personal document management system for organizing and archiving documents. It supports automatic fetching from email and IMAP, tagging, and full-text search. It is designed for self-hosting by individuals and small teams. ([Read more](/details/docspell.md)) `Open Source` `Self-Hosted` `Personal DMS` `OCR` `Archiving`
- [Mayan EDMS](https://www.mayan-edms.com/) - Mayan EDMS is an open-source electronic document management system with features for document indexing, versioning, and workflow automation. It provides a web interface and REST API for self-hosted deployment. The project is licensed under Apache 2.0. ([Read more](/details/mayan-edms.md)) `Open Source` `Self-Hosted` `API` `Workflow` `DMS`
- [OpenKM](https://www.openkm.com/) - OpenKM is an open-source document management system offering document control, metadata, and workflow automation. It can be deployed on-premises or in the cloud and includes a web interface and APIs. Licensing includes a community edition and commercial subscriptions. ([Read more](/details/openkm.md)) `Open Source` `Self-Hosted` `API` `Workflow` `DMS`

## Paperless & Scanning

- [Paperless-ngx](https://paperless-ngx.com/) - Paperless-ngx is an open-source document management system that scans and indexes paper documents into a searchable digital archive. It is designed for self-hosted personal or small-office use and supports OCR and automated matching. The software is released under the AGPLv3 license. ([Read more](/details/paperless-ngx.md)) `Open Source` `Self-Hosted` `Paperless` `OCR` `Scanning`
- [Papermerge](https://papermerge.com/) - Papermerge is an open-source document management system focused on archiving and managing scanned documents. It supports OCR, version control, and user permissions for self-hosted environments. It is available under the AGPLv3 license. ([Read more](/details/papermerge.md)) `Open Source` `Self-Hosted` `Paperless` `Scanning` `OCR`
